# Hiking-adventures-Management-System-Oracle-PL-SQL-Project
Hiking database PL/SQL solutions
This is a complete Oracle PL/SQL Database System for managing hiking trail bookings, guides, and clients. Developed as a summative assessment demonstrating advanced database programming concepts.
It manages hiking guides, clients, trails, and event bookings, generates client trail reports with costs, displays trail events with participant counts, provides client booking details by date and implements role-based security and data protection
